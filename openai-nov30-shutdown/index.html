OpenAI Nov 30, 2026 shutdown fix

OpenAI has published shutdown dates for Agent Builder, reusable prompt objects, the v1/prompts API, and the Evals dashboard and API. The Assistants API is already sunset. This async sprint maps what in your code and item list depends on those pieces and returns a ranked fix list that uses only tools you already have.

One site or app per sprint. No logins, calls, or screen-shares.

Who it is for

Small U.S. businesses and agencies with live chat or automation on Agent Builder, ChatKit hosted-workflow sessions, prompt objects, Evals, or leftover Assistants API code — and code or files you can send for review. Not for teams that have already migrated.

What you send (email only)

Everything goes to firstmoverprojects@gmail.com.

  1. Item list (max 25 items): Agent Builder workflow names and wf_ IDs, ChatKit embed locations, pmpt_ references, eval names, models in use.
  2. Code that calls OpenAI: Public repo URL or relevant files attached. Include Agents SDK export if you have it. We never take repo access — no invites, deploy keys, or tokens.
  3. Edge cases you know: Error handling, timeouts, tool calls, dashboard-only prompt edits, and what must behave the same every time.
  4. Tools already in place: Repo host, CI, hosting, OpenAI plan — so the fix list stays inside what you already have.

Send code with all keys and secrets removed. If we find one, we stop, ask you to rotate it, and delete our copy. We read code only; we do not run, deploy, or change anything in your systems during the sprint.
