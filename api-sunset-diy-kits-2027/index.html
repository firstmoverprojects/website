API Token to OAuth Switch Kit for Zendesk Teams

Zendesk is ending API token access on a published schedule: no new API tokens after October 27, 2026, and all API tokens stop working April 30, 2027.

The kit walks through inventorying token use, switching each integration to OAuth (and options for webhooks), and testing before the cutoff — built from Zendesk's own help and developer pages.

SOAP to REST Switch Kit for Microsoft Advertising API Scripts

Microsoft Advertising's SOAP API is scheduled for full deprecation on January 31, 2027. Integrations still on SOAP need a move to the REST APIs on Microsoft's published timeline.

The kit covers finding SOAP calls in your code, the per-SDK migration steps from Microsoft Learn, how to find each operation's REST URL, and validation tests, for your developers to run.

Microsoft — Migrate to REST

Move-Out Kit for ProductCart Store Owners

NetSource-managed ProductCart hosting ends January 11, 2027 ( sunset FAQ). A do-it-yourself checklist: what to export, what won't carry over as-is, an old-to-new URL map template, and cutover-day tests. It notes which old URLs Shopify can't redirect natively (paths starting with /shop, and query-string URLs that may not work), and leaves any routing choice to you.
