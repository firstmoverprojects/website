What to check

  1. Read both end dates on Microsoft's pages before you pick a cutoff. The lifecycle page says Windows Server 2016 follows the Fixed Lifecycle Policy. Support dates on that page are in Pacific Time. The Extended End Date is 1/13/2027 6:59:59 AM for Datacenter, Essentials, MultiPoint Premium, and Standard. Mainstream support ended 1/12/2022 6:59:59 AM Pacific Time. Microsoft says containers released with Windows Server 2016 follow the same lifecycle dates. The ESU article says end of support is January 12, 2027.
  2. If you need security updates after that, use the Windows Server 2016 section of the ESU article. Microsoft says ESUs provide Critical and Important security updates for up to three years, through 2030, and do not include new features, customer-requested nonsecurity hotfixes, or design change requests.
  3. The same section says ESUs support Standard and Datacenter, and that you connect servers with Azure Connected Machine agent version 1.62 or higher. Microsoft says you can then enroll through the Azure portal or Azure Policy. Configuration in the Azure portal starts August 3, 2026. Billing for ESUs enabled by Azure Arc begins January 13, 2027.
  4. Microsoft says buying ESUs requires Software Assurance through a volume-licensing program such as an Enterprise Agreement, Enterprise Agreement Subscription, Enrollment for Education Solutions, Server and Cloud Enrollment, or Microsoft Open Value. If the machines are licensed through SPLA or with a Server Subscription, Microsoft says Software Assurance is not required.
  5. Microsoft says not to use Azure Arc to deliver ESUs to virtual machines on Virtual Desktop Infrastructure. Use Multiple Activation Keys for those VDI systems. Microsoft also says Azure Arc-enabled servers used for these ESUs are not available in Azure operated by 21Vianet regions at this time.
  6. If the server is Windows Server 2016 Essentials, open the Essentials end-of-support page. Microsoft says support ends on January 12, 2027, that Essentials is the last version with the full classic Essentials experience, and that Anywhere Access, Remote Web Access (RWA), and the remotewebaccess.com domain and dynamic DNS integration are supported only through that date.
  7. The ESU article lists network endpoints and certificate authorities for the Azure Arc connection. Open that section on Microsoft's page before you connect a server. This page does not copy that endpoint list, and it does not state an ESU dollar price, because the article sections above do not print one.

FAQ

When does Windows Server 2016 support end?

Microsoft's Azure Arc Extended Security Updates article says Windows Server 2016 reaches end of support on January 12, 2027. The Windows Server 2016 lifecycle page lists the Extended End Date as 1/13/2027 6:59:59 AM Pacific Time for Datacenter, Essentials, MultiPoint Premium, and Standard. Microsoft's Essentials page says support for Windows Server 2016 Essentials ends on January 12, 2027.

What do Windows Server 2016 Extended Security Updates include?

Microsoft says Extended Security Updates for Windows Server 2016 provide Critical and Important security updates for up to three years, through 2030. Microsoft says they do not include new features, customer-requested nonsecurity hotfixes, or design change requests.

Which editions does the Azure Arc ESU article name?

Microsoft says Windows Server 2016 Extended Security Updates support Standard and Datacenter editions, and that the Azure Connected Machine agent should be version 1.62 or higher. The lifecycle page lists a wider set of editions for the support dates themselves: Datacenter, Essentials, MultiPoint Premium, and Standard.

When can I configure those ESUs, and when does billing start?

Microsoft says you can configure Windows Server 2016 ESUs in the Azure portal starting August 3, 2026, and that billing for Windows Server 2016 ESUs enabled by Azure Arc begins January 13, 2027.

What happens to Remote Web Access on Windows Server 2016 Essentials?

Microsoft's Essentials end-of-support page says Anywhere Access, Remote Web Access (RWA), and the remotewebaccess.com domain and dynamic DNS integration associated with Remote Web Access are supported only through January 12, 2027. The same page says Windows Server 2016 Essentials is the last version that includes the full classic Windows Server Essentials experience.
