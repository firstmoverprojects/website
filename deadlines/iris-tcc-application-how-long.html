How long does an IRIS TCC application take?

Publication 5717 says to allow up to 45 calendar days for IRIS Application for TCC processing. You can check the status on the Application Summary page. Information returns may not be transmitted through the IRIS Taxpayer Portal until a TCC has been assigned. If the application stays in Submitted Pending Review for more than 45 days, Publication 5717 says to contact the Help Desk.

Who can apply, and what you receive

Publication 5717 says any entity with an employer identification number (EIN) can apply for an IRIS Taxpayer Portal TCC. When the application is completed, Publication 5717 says a five-character alphanumeric TCC that begins with the letter D is assigned. An approval letter is sent by U.S. mail. Publication 5717 says to monitor the application and start using the TCC immediately after assignment.

The IRIS e-file page says that to use the IRIS Taxpayer Portal you need an IRIS TCC, that this code identifies your business when you e-file, and that it can only be used for IRIS. The same page says filers who use third-party software, or who develop their own software, can use IRIS Application to Application for larger volumes. That channel has its own IRIS A2A TCC.

The E-file information returns page says not to delay the TCC application. It says processing may take up to 45 days. It also says IRIS TCCs start with the letter D and FIRE TCCs start with a numeric character.

FAQ

How long does an IRIS TCC application take?

Publication 5717 says to allow up to 45 calendar days for application processing.

When does the IRIS TCC processing time start?

Publication 5717 says each Responsible Official must sign the Application Submission page with a 5-digit PIN. The application is processed after all Responsible Officials have entered their PIN and accepted the Terms of Agreement.

Can I file in the IRIS Taxpayer Portal before the TCC is assigned?

Publication 5717 says information returns may not be transmitted through the IRIS Taxpayer Portal until a TCC has been assigned.

Does a FIRE TCC work as an IRIS TCC?

Publication 5717 says a TCC obtained for FIRE cannot be used in the IRIS Taxpayer Portal. The FIRE page says current FIRE users must complete a separate IRIS Application for TCC. The IRIS page says the IRIS TCC can only be used for IRIS, and it describes that code as 5 digits. Publication 5717 says the assigned IRIS Taxpayer Portal TCC is a five-character alphanumeric code that begins with the letter D.

Is November 9, 2026 the deadline to apply for an IRIS TCC?

No. November 9, 2026 was the last day to make changes to existing Information Returns (IR) Applications for TCCs, the FIRE applications; those applications are now read-only. The IRS is no longer accepting new IR Applications for TCCs. The FIRE page says existing applicants could update those applications through November 9, 2026, after which those applications became read-only and are retained for historical reference. An IRIS Application for TCC is separate. Publication 5717 says to allow up to 45 calendar days for that IRIS application.

What if the IRIS TCC application is still pending after 45 days?

Publication 5717 says if the application is in Submitted Pending Review status for more than 45 days, contact the Help Desk. The IRIS e-file page lists the help desk as Monday through Friday, 7:30 a.m. to 7 p.m. Eastern time, toll-free 866-937-4130.
