1. Run this read-only command

In Exchange Online PowerShell (it only reads settings; it changes nothing):

Get-OrganizationConfig -RetrieveEwsOperationAccessPolicy | Format-List EwsEnabled,EwsAllowedAppIDs,EwsApplicationAccessPolicy,EwsAllowList,EwsBlockList

Microsoft notes the -RetrieveEwsOperationAccessPolicy switch is needed to return the AppID list. App IDs are not passwords, but you can blank them out: the decoder only needs to know whether the list has entries.

    Microsoft's table, in plain English

    EwsEnabledOnce the phased change reaches your tenant
    Empty (Null, the default)Changed to False during Microsoft's rollout, which blocks EWS for all apps
    True, AppID list has entriesOnly apps on the list can use EWS
    True, list missing or emptyNo EWS allowed (cross-tenant organization relationship traffic still works)
    FalseAll EWS blocked
    Any value, from Apr 1, 2027EWS fully and permanently disabled
