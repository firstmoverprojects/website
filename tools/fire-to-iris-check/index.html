What the IRS says

In news release IR-2026-99 (Aug. 24, 2026) and on the IRS FIRE page, the IRS states that the Filing Information Returns Electronically (FIRE) system is retiring after the 2026 filing season and lists three November 2026 cutoffs: Nov. 1, 2026 (last day to file test information returns through the FIRE Trading Partner Test System), Nov. 9, 2026 (last day to make changes to Information Returns Applications for Transmitter Control Codes, after which existing IR TCC applications become read-only), and Nov. 19, 2026, at 3 p.m. ET (last day to file information returns through the FIRE system). IRS IR-2026-99: Information return e-file system transitioning to a new platform · IRS: Filing Information Returns Electronically (FIRE)

Starting Jan. 1, 2027, the Information Returns Intake System (IRIS) is the only electronic filing system for information returns, including prior-year returns and corrections. Current FIRE users must complete a separate IRIS Application for TCC to file in IRIS. The IRS notes that the IRIS Taxpayer Portal is a free, web-based filing system that allows filers to e-file up to 100 returns at a time (by typing information directly or uploading a CSV file using the IRS template). IRS: E-file information returns with IRIS

1. Check your filing setup and paste your CSV header row (optional)

Privacy guard: Do not paste real taxpayer names, Social Security numbers, EINs, or TCCs. Paste only column header names (for example: Vendor Name, Tax ID, Address, Total 1099-NEC Nonemployee Compensation). Any 9-digit number pattern is automatically ignored and flagged.

You may still be on the IRS system that is closing.

Test files stop on Nov 1, 2026. Changes to an old IRS application stop on Nov 9, 2026. The last day to file on the old system is Nov 19, 2026, at 3 p.m. Eastern Time. On Jan 1, 2027, the new system is the only way to file.
