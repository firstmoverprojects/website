What the IRS says

In news release IR-2026-99 (Aug. 24, 2026) and on the IRS FIRE page, the IRS states that the Filing Information Returns Electronically (FIRE) system is retiring after the 2026 filing season and lists three November 2026 cutoffs: Nov. 1, 2026 (last day to file test information returns through the FIRE Trading Partner Test System; that date has passed), Nov. 9, 2026 (last day to make changes to Information Returns Applications for Transmitter Control Codes, after which existing IR TCC applications become read-only; that date has passed, so those applications are now read-only), and Nov. 19, 2026, at 3 p.m. ET (last day to file information returns through the FIRE system; this is the next IRS date). IRS IR-2026-99: Information return e-file system transitioning to a new platform · IRS: Filing Information Returns Electronically (FIRE)

Starting Jan. 1, 2027, the Information Returns Intake System (IRIS) is the only electronic filing system for information returns, including prior-year returns and corrections. Current FIRE users who will e-file in IRIS themselves must complete a separate IRIS Application for TCC. If a provider or paid e-file service transmits for you, ask whether they file under their own IRIS TCC. The IRS notes that the IRIS Taxpayer Portal is a free, web-based filing system that allows filers to e-file up to 100 returns at a time (by typing information directly or uploading a CSV file using the IRS template).
