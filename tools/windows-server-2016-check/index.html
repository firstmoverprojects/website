Windows Server 2016 check

Four plain questions. They run in this browser. The answers are not saved and are not sent.

Microsoft's Windows Server release information lists the extended support end date for Windows Server 2016 (version 1607) as 2027-01-12. The product lifecycle page lists the Extended End Date as 1/13/2027 6:59:59 AM Pacific Time (Redmond, WA, USA). This page counts days until Jan 12, 2027.

The lifecycle page says Windows Server 2016 follows the Fixed Lifecycle Policy. The editions listed there are Datacenter, Essentials, MultiPoint Premium, and Standard. The release information row lists Datacenter, Essentials, and Standard.

Microsoft support for Remote Web Access and remotewebaccess.com ends Jan 12, 2027.

Microsoft's Windows Server 2016 Essentials end of support page says: "Microsoft support for Remote Web Access and remotewebaccess.com as part of Windows Server 2016 Essentials ends on January 12, 2027." That page also says support for Windows Server 2016 Essentials ends on January 12, 2027, and that Windows Server 2016 Essentials is the last version that includes the full classic Windows Server Essentials experience. It lists Remote Web Access (RWA) and the remotewebaccess.com domain and dynamic DNS integration as supported only through January 12, 2027.

Four questions

How this page picks one article to open first: it is a reading order from your answers, not a verdict about your servers.

  • No: this is not Windows Server 2016, so the page does not pick a move. It points you to Microsoft's lifecycle search.
  • Not sure of the version: confirm the version, then answer again.
  • Yes, and about 6 or more servers: move to cloud.
  • Yes, and Essentials or staff use Remote Web Access, and not 6 or more servers: migrate to a newer server.
  • Yes, one server, edition Standard, Datacenter, or not sure, and Remote Web Access is not Yes: upgrade in place.
  • Other Yes answers (2 to 5 servers, or the server count is not sure, and not the Essentials or Remote Web Access case): migrate to a newer server.

Three Microsoft articles


These descriptions use Microsoft's own wording for what each article is about. This page does not rank them as better or worse for every shop. The result above names one article to open first.


Upgrade in place


Microsoft's upgrade plan page says an in-place upgrade installs a newer version of Windows Server over the existing one, keeping your settings, server roles, features, and data. That page's installation-media table lists Windows Server 2016 as Yes to Windows Server 2019, Windows Server 2022, and Windows Server 2025. The steps are in Upgrade Windows Server in Place. This page does not know your roles or whether that table row applies to your edition.


Migrate to a newer server


Microsoft's upgrade plan page says migration moves roles or features from a source server to a different destination server running Windows Server. The roles and features article says migration moves roles and features to a new server running a newer version of Windows Server. This page does not know which roles you run.


Move to cloud


Microsoft's Azure Migrate overview says Azure Migrate is a service that helps you decide on, plan, and execute your migration to Azure. That overview says you can migrate physical servers to Azure. This page does not know whether a cloud move fits the workloads on your servers.
